## Evidence and root causes found

- P0: Android BLE primary advertisement exceeds the legacy 31-byte packet budget.
- P0: Swift local HTTP connection handlers lack a retained owner.
- P0: Room join/approval and refresh rotation have concurrent-write races.
- P1: Socket recreation on NetInfo changes, subscription ordering and missed replay break recovery.
- P1: GATT refresh interval exceeds peer expiry; discovered hosts disappear.
- P1: Playback correction occurs while unloaded/buffering; historical RTT estimator cannot adapt.
- P1: Chat REST fallback after lost acknowledgement creates duplicates.
- P2: Fixed onboarding page dimensions, constrained rows and non-scrolling keyboard sheets overflow.
- P2: Supplied generated mobile configuration contains a personal LAN address.
